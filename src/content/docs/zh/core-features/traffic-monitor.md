---
title: 流量监控
description: 实时检查、过滤和分析网络流量。
---

流量监控是 RelayCraft 的核心功能，提供流经代理的所有 HTTP 和 HTTPS 流量的实时视图。它允许您检查请求详情、过滤特定流量并分析性能。

## 主界面

流量视图显示网络请求列表，包含关键信息：
-   **来源**: 发起请求的应用或进程，以图标展示（常见浏览器和工具显示真实应用图标）。悬停可查看进程名与 PID。
-   **方法**: HTTP 方法 (GET, POST 等)。
-   **状态**: HTTP 状态码 (200, 404, 500 等)，带颜色编码。
-   **主机与路径**: 目标服务器和资源路径。
-   **大小**: 响应体大小。
-   **时间**: 请求持续时间。
-   **类型**: 内容类型 (JSON, HTML, Image 等)。

## 流量过滤

使用顶部的 **过滤栏** 来筛选流量列表。

### 基本过滤
输入任意文本以匹配 URL、方法或状态码。
-   `api` 匹配包含 "api" 的请求。
-   `POST` 匹配 POST 请求。
-   `404` 匹配状态码为 404 的请求。

### 高级过滤语法

RelayCraft 支持强大的高级搜索语法，允许您精确地筛选流量。

**快速过滤关键字**:
-   `method:POST` - 仅显示 POST 请求（别名 `m:`）。
-   `status:4xx` - 显示状态码为 400-499 的请求 (支持 `2xx`, `3xx`, `4xx`, `5xx`；别名 `s:`)。
-   `status:4xx,5xx` - 单个关键字内用逗号表示并集。
-   `domain:api` - 按域名子串匹配（别名 `d:`、`host:`）。
-   `source:chrome` - 按流量来源匹配：客户端 IP、应用名或进程名（别名 `src:`）。
-   `process:curl` - 按本地进程名匹配（别名 `proc:`）。
-   `pid:4321` - 按进程 PID 精确匹配。
-   `ip:192.168` - 匹配客户端或服务端 IP。
-   `type:json` - 显示 Content-Type 为 JSON 的请求（别名 `t:`）。
-   `header:authorization` - 匹配请求/响应头的名称或值；`header:key:value` 匹配指定头（别名 `h:`）。
-   `body:token` - 在响应体中搜索（别名 `resbody:`）。
-   `reqbody:email` - 在请求体中搜索（别名 `rb:`）。
-   `size:>1mb` - 显示响应体大于 1MB 的请求 (支持 `kb`, `mb`, `gb`；别名 `sz:`)。
-   `duration:>500ms` - 显示耗时超过 500 毫秒的请求 (支持 `ms`, `s`, `m`；别名 `dur:`)。
-   `-domain:google` - 排除域名包含 "google" 的请求（也可用 `!domain:google`）。

**组合查询**:
-   **交集 (与)**: 使用空格分隔不同类型的条件。
    -   例如: `method:POST type:json` (同时满足是 POST 请求且类型为 JSON)。
-   **并集 (或)**: 输入多个相同类型的条件。
    -   例如: `status:4xx status:5xx` (显示 4xx 或 5xx 的请求)。
-   **排除**: 在条件前加 `-` 号。
    -   例如: `-domain:google` (排除谷歌相关的请求)。
-   **数值比较**: 支持 `>` (大于) 和 `<` (小于)。
    -   例如: `size:>1mb` (大于 1MB)。

### 高级选项
-   **正则**: 启用正则表达式模式以进行复杂的模式匹配。
-   **区分大小写**: 切换过滤器的区分大小写功能。
-   **仅显示匹配项**: 完全隐藏未匹配的请求，而不仅仅是使其变暗。

### AI 过滤
点击过滤栏中的 **AI 助手** 图标，使用自然语言生成过滤模式。
-   示例：*"显示所有发往 api.example.com 的失败 POST 请求"*

## 抓包范围

过滤改变的是你**看到**的内容，抓包范围改变的是**被记录**的内容。点击过滤栏旁的 **抓包范围** 按钮，可按进程限定捕获：

-   **仅包含**：逗号分隔的进程名——只记录这些进程产生的流量。
-   **排除**：逗号分隔的进程名——丢弃这些进程产生的流量。
-   **最近进程**：基于近期观察到的来源，提供一键填入的建议。

范围在引擎层生效，被排除的流量不会进入会话。要快速聚焦单个应用，右键任意请求选择 **仅记录 `<进程名>`** 即可。

## 流量详情

点击列表中的任何请求，将在右侧打开 **流量详情** 面板。

### 请求与响应
-   **Headers**: 查看和复制 HTTP 标头。
-   **Body**: 查看请求/响应体，支持 JSON、XML、HTML 等的语法高亮。
    -   支持压缩代码的格式化显示 (Pretty-print)。
    -   图片响应的预览功能。
-   **Cookies**: 查看解析后的 Cookie。

### 概览
-   **耗时**: 请求生命周期的详细细分 (DNS, TCP, SSL, TTFB, Download)。
-   **常规**: 协议版本、TLS 版本、连接详情以及来源进程/应用归属。

### 诊断包

在流量详情面板可导出**仅含元数据的诊断包**——一份脱敏后的流量快照（耗时、标头、规则命中、引擎状态），用于向他人求助时分享。请求/响应体永远不会包含在内。

## 上下文操作

右键点击任何请求以访问快捷操作：

-   **复制**: 复制 URL、cURL 命令或请求/响应体。
-   **重放**: 立即重新发送请求。
-   **编辑重发**: 在发送前在编辑器中修改请求。
-   **创建规则**: 基于此请求快速创建本地映射 (Map Local) 或重写 (Rewrite) 规则。
-   **添加断点**: 拦截匹配此 URL 的后续请求，以便即时修改。
-   **仅记录 `<进程名>`**: 应用抓包范围，只记录产生此流量的进程。

## 断点

断点允许您暂停请求或响应，以便在继续之前对其进行修改。

1.  **设置断点**: 右键点击请求或使用断点管理器。
2.  **触发**: 当发起匹配的请求时，RelayCraft 会暂停执行。
3.  **编辑**: 您可以在暂停状态下修改标头、正文或状态码。
4.  **恢复**: 点击 "恢复" 将修改后的请求/响应发送到目的地。
